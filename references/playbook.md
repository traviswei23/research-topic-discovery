# 从线索到题目的操作手册

按当前瓶颈选用下列提示词。方括号替换为项目材料，输出需要归入同一候选卡。每轮把取得的新信息加回上一轮的卡片，再决定深挖还是换分支。

## 访谈：确定问题归谁回答

| 起点 | 可直接问研究者 | 记录怎样改变后续工作 |
|---|---|---|
| 领域名 | “假设明天能弄清这个方向里一件事，你最想解释哪种现象，或者消除哪项限制？” | 无具体例子时，给出机制解释、测量边界、系统改进的不同入口，请其指出最关心的一类。 |
| 单篇论文 | “这项结论要在哪些条件下才成立？如果你只能核实一项前提，会选哪项？” | 保留文献位置，分开记作者的前提与读者的假设。 |
| 实验失效 | “原来预期怎样？实际观察到什么？是否有一次在其他条件下成功了？” | 成败配对形成初始比较。先对照装置、测量和条件，再设想机制。 |
| 想用一种技术 | “如果这种技术没有改善指标，哪个问题仍值得回答？” | 找出能证明该技术有必要的朴素对照；若找不到，回到研究对象。 |
| 项目受阻 | “哪一项限制移除后，其他问题就能前进？哪些条件现在可以改变？” | 将技术执行故障、资源限制和科学假设分开，分别决定修复、改设计或改题。 |

一次选最能改变推荐的问题。可从六种角度追问：术语具体指什么、说法依赖什么前提、证据从何而来、另一立场会怎样解释、相反结果意味着什么、当前问法是否漏掉其他可能。先重述对方真正承认的内容，允许对方收回前提。若用户喜欢独立出稿，依据手头材料综合，列出影响选择的待确认条件即可。

## 检索：先确认难点仍在前沿

用四组词分别覆盖领域和对象、方法的操作特征、同类问题、已经解决它的人可能如何命名其方案；查同义词、旧名、跨学科对应词。把论文分成直接前作、邻近对照与背景。精选一篇最近似前作核对全文，再找一个独立来源判断瓶颈的范围。为每条主线画出旧方法→改进→尚未解决的条件；如果旧路线已解决难题，要说明新情境为何破坏原有解法。数据库可按所在学科和访问能力选择。沁言、Zotero、OpenAlex 或其他平台只承担检索与整理角色。记录真实查询、时间、版本和文献位置。

**检索提示词**　“用与你支持的构想相反的立场搜：[某机制] 已经被 [别名或传统方法] 完成了吗？把最相似论文的操作、所用条件与结论列出来。无法读到关键段落的项目列为待核，不给相似程度的确定判断。”

## 发散：为同一个难点构造多个不同解

| 操作 | 给执行者的提示 | 判断它是否真的给出新候选 |
|---|---|---|
| 问题先行与方法先行 | 从一个高代价失败出发，追问其原因；再从新可用方法出发，查什么问题过去因资源限制而无法测。 | 两个方向都要有独立的研究动机和具体观察对象。 |
| 抽象与还原 | 去掉领域名，用输入、过程、输出描述关系；升一级看同构问题，再降一级落到可测变量。 | 每个抽象词需能对应一次操作、一个观测或可检验预测。 |
| 逆向与失效 | 反转惯用假设，构造最容易让现有解法失败的情形，记录简化环节或拿掉组件后会怎样。 | 破坏条件后应该会看到一个具体、可区分的效应。 |
| 新条件与尺度 | 轮换观测尺度、时间窗、样本范围、资源预算和物理约束，比较松紧两种状态。 | 禁止通过放宽任务标准把旧结果改名为进展。 |
| 测量与诊断 | 设想两个机制会给出相同终点，但中间过程不同。哪个量能尽早把它们区分开？ | 写出相反预测和测量条件。 |
| 角色变化 | 分别从理论研究者、实验人员、仪器使用者和反方评议者看同一问题；让各自先独立写答案。 | 归并时判断根本假设或可检验后果有无改变。 |
| 借用与重组 | 找一个来源领域，写清源概念、目标概念、对应关系、尺寸或单位、成立条件、相反条件。 | 写出可迁移机制及失配风险。两部件组合要给出区别于简单相加的预测。 |
| 反常与对赌 | 选一个被默认接受的判断，写出可能的反证与高回报解释；同时写更朴素、风险较小的解释。 | 两种解释须能在同一公平比较中作出不同预测。 |
| 替代与第一性原理 | 保留基本规律和可用资源。如果取消当前通用器件/算法，最简单可行路线是什么？ | 明确哪个约束绝对不可动，哪个只是惯例。 |
| 趋势与库存 | 区分论文数量变化、新测量能力出现、长期问题突然可解；对照既有构想与被放弃原因。 | 说明“为什么现在可做”，查旧名和早期结果，避免把热度当价值。 |

当候选已呈现不同机制，直接转入比较。用户要广泛探索时，可以先发散十来个，再按假设、方法族和验证手段归并；每个保留分支只再拓展仍有信息增益的部分。若新分支只是同义改写、读到的最新证据不再改变排序，或达到用户的时间范围，停止并说明原因。不要让深搜淹没用户要做的单个决策。

## 收敛：把候选推到可以接受反例

1. **形成操作链。** 请写“线索来自哪里→认为什么步骤失效→改动哪一环→改变什么中间量→应在哪个观测中看出来”。检查变量是否有来源、依赖是否循环，哪一步只是愿望。
2. **核对最简单替代。** 写出成本和可用信息相同的朴素对照。如果对照也应有效，追问它究竟被什么已知事实排除。不能排除时，比较两种解释或改做适用边界研究。
3. **试着推翻。** “最强反方会找哪篇论文，或提出什么反例？若哪条假设为假，题目仍有研究价值？”可按问题、机制、发现、使用情境四列比较。初筛没有找到近似作时，保留检索范围。
4. **预演最小验证。** 写出正对照、负对照、观测量和判定。计算方法可在权限内用一个小实例核对步骤、极端输入和简单对照；未执行的预演写为计划。验证性研究先固定问题和判据，已有观察仅用于探索或独立复核。资源量不明时可先做运行耗时、测量范围或样本可得性试探。
5. **判断去留。** 对科学价值、信息增益、资源可行性、失败代价各给“高、中、低或未知”并写依据。阻断项不被加权均分掩盖。对高潜力候选保留一个检验高风险前提的廉价动作；保留的备选应在机制、风险或资源上补足首选。
6. **记下决策。** 可表述为推进、先补证、改题、暂存。说明哪一条新证据会使选择逆转。对用户已认可的主线，只有新事实或目标变化才重开比较。集中验证最不确定的一个因素，其余参数暂时固定；若关键资源已不可及，沿决策树走备用路径。

**评议提示词**　“先按相反立场阅读 [候选卡、最接近前作、材料台账]。列一条有出处、足以动摇核心主张的反驳，一项能令你改判的比较。若证据只动摇适用范围，请写出收窄后仍成立的版本。别为保住候选而悄悄降低原失败判据或改小已报成本。”
