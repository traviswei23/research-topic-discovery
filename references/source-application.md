# 原 20 个技能如何改变选题决定

在[固定来源表](sources.md)按编号查原文，在[配套材料表](resources.md)查模板、提示词和脚本。下表给出每项操作的触发条件、要留下的证据，以及保留原方法时所作的取舍。运行中共用一次检索或一次试算即可回答多项问题。

| 原入口 | 何时使用、实际操作 | 结果放在哪里、怎样取舍 |
|---|---|---|
| 1 socratic-research-topic | 研究者愿意对话时，先记其亲自认可的判断，只从最影响选择的概念、前提、证据或反例追问。 | constraints 保留已确认的约束。直接要结果时执行者在分支中比较不同解释，避免为收齐六类回答而中断。 |
| 2 develop-research-ideas | 增量重开时先恢复已选题及旧证据。把现有前作共有的假设写成一行，再找违反假设的条件。 | rounds 记为何重开，卡上写两种相反结果各说明什么。既有实验观察只作生成线索。 |
| 3 research-idea-finder | 检索四组词后画方法继承关系，选一个决定推荐的瓶颈，跑朴素、极端和负对照。 | queries、papers、pilot 记录操作和低成本结果；无运行条件注明影响。 |
| 4 scientific-brainstorming | 各视角独立提案，揭示后结构聚类，先定评价轴再排名，改变一个有争议权重看首选是否翻转。 | ideas 与 review 留出少数意见、替代排序、参与者身份，单人视角标明自审。 |
| 5 research-ideation | 用谁、何物、何时、何地、为何、如何梳理未知范围。区分方法缺口、证据冲突和数据可达性。 | question 一题只问一种关系，next 给出第一项里程碑。按领域选库，不依赖某个参考文献软件。 |
| 6 scientific-problem-selection | 新方向先定衡量目标，受阻项目先定位瓶颈。固定一个核心变量，再有意放松一项限制，比较风险和机会。 | constraints、rounds、resources 记录风险是否可逆及预案，用户设定的硬条件不能在试算中放宽。 |
| 7 idea-generation | 广发散时轮换问题先行、方法先行、矛盾和尺度；用文献搜索校正，再逐个给出价值、新意、资源与风险的依据。 | ideas 归并到不同机制，再作一页卡。原版 10–20 的候选数用于广探索，完成按用户目标及分支多样性判断。 |
| 8 trend-grounded-opportunity-finding | 把新数据、测量能力或技术变化连到此前不能回答的问题，逐项对照历史题库存。 | value 写“为何现在能做”，撤销已解决的主张。发文量单独增加只记背景。 |
| 9 research-idea-discovery | 将独立选题、路线重开及下游编排区分，在选题、修改范围、继续生成和终止之间作明确决定。 | decision、selected、next_step 对应真实可交接的卡。快速相似性搜索只用于排序，深查另有门槛。 |
| 10 light-idea-generation | 每个主选从证据线索追到机制改动和最小判别。若是 A+B 组合，就指定拆掉 A 或 B 后会在哪种条件下看到不同预测。 | papers→prior→comparison→pilot。合并字面不同但预测相同的卡；缺失附件见[来源可用性](source-availability.md)。 |
| 11 research-brainstorm | 提出最强质疑后强制尝试一次改换问题框架。例如不再问性能能否提升，而问基线何时会失效。 | rounds 对照改变前后可测量的差异。只按实际读取的前作写潜在贡献，不替同行预判发表结果。 |
| 12 qinyan-topic-analysis | 可用沁言时按其支持的数据库分别检索中文、英文术语并保存实际响应。也可直接查专业出版源与索引。 | queries 实记库、词和数量，成功连接一个网关不能算所有数据库都已查。原版按库大批量收集的目标随相关性与预算调整。 |
| 13 cross-field-synthesis | 写源域、目标域各自的输入量、单位、映射和假设，故意举一个映射破裂的情形，决定能否借用机制。 | mechanism、prediction、falsifier 保存映射及破裂条件，不要求部署作者的知识库布局。 |
| 14 scientific-ideation | 先发散后连机制，面对多个使用者分别记录认可标准，倒排从定题日到第一项可能失败的验证。 | resources 和 next 说明稀缺资源与时间冲突。与第 6 项共享风险评估，避免相同判断重复计票。 |
| 15 inspire-me | 分别建立“想要的效果→可能机制”与“本领域证据→成立条件”两棵树，找可测的连接点，换反证搜索检验。 | rounds 可恢复为何推进或放弃。只在能说明先验和似然时才作定量更新。 |
| 16 research-question | 按描述、比较、关联或解释确定提问方式，检查可行性、研究者兴趣、价值和约束。 | observable、falsifier 对应真实能取得的量，描述性任务无须编一个因果机制当作既定事实。 |
| 17 define-research-question | 把问题收窄到对象、单位、时空与排除项，给主备版本，并把每个版本对到一种证据。 | question、observable、comparison；只有设计能区分原因时才用因果措辞。 |
| 18 paper-topic-selection | 从现实、文献和方法分别起题，按价值、新意、实施和本人匹配取舍，查数据可得性，模拟一次答辩。 | review、pilot、next 给出一项可实施的近期行动及失败时的备选；评分凭据优先于加权总和。 |
| 19 framing-research-questions | 先确定分析单位、两个预测、代理指标及会改变决定的判据，再看结果。把环境是否能跑与假设是否成立分开。 | protocol 指向事先保存的判据，result 指向真实结果，出乎意料的模式另起一轮探索。 |
| 20 brainstorm | 宽枚举反演、替换、尺度和约束，深挖只分配给能区分现存解释的分支；写节点消耗与何时停止。 | 归并编号、rounds 与 stop 保留剪枝理由。若要求多个主选，单条分支成功不足以结束全局工作。 |

源入口和一批附件在旧版已有中文转述。新版默认要求跑实际检索、试验与反方检查，并按[执行说明](execution.md)留存可交接的输入、观测和去留。具体选题不需要逐一调用 20 套原环境。
